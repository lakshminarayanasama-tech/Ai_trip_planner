# ✈️ AI Travel Planner (CrewAI + Groq + Gradio)

Multi-agent travel planner that generates routes, cost estimates and a day-wise itinerary.

**Setup:** add a secret named `GROQ_API_KEY` in Space → Settings → Variables and secrets.
